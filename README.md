# A Little Sorry For You ♡

A romantic, thoughtful, and interactive apology website built for your girlfriend. Designed with a **Pinterest Coquette Aesthetic**, delicate animations, hand-crafted vector bouquets, interactive letter unfolding, and sincere words.

---

## 🎀 Aesthetic & Highlights

- **Romantic Pinterest Coquette Theme**: Soft baby pinks, blush tones, cream paper texture, satin bows, delicate wax seal, and gentle shadows.
- **Handcrafted SVG Flower Bouquet**: Includes pink roses, white baby's breath, soft pastel peonies, sage eucalyptus leaves, origami wrapping paper, and fluttering ribbons. Tap flowers for sweet whispered thoughts!
- **Interactive Wax-Sealed Apology Letter**: 3D animated envelope flap, breaking wax seal, sliding parchment, and the heartfelt letter with handwritten sign-off.
- **Three Reassurance Cards**: "You matter to me", "I'm listening, always", and "I want to do better", accompanied by a "Send a little hug back ♡" button.
- **Ambient Melody**: A soft, soothing music-box lullaby synthesized via the Web Audio API (offline, zero external audio dependencies).
- **Responsive & Modern**: Built with Next.js 14 App Router, React 18, TypeScript, Tailwind CSS, and Framer Motion.

---

## 🚀 Getting Started

To run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the surprise.

To build for production:

```bash
npm run build
npm run start
```
